# Green Hands 333 - 天然じゃこうねこコーヒー

Green Hands 333の公式ウェブサイトです。

## サイト構成

- `index.html` - トップページ
- `products.html` - 商品一覧ページ
- `product1.html`, `product2.html`, `product3.html` - 商品詳細ページ
- `css/style.css` - スタイルシート
- `js/script.js` - JavaScript
- `image/` - 画像ファイル

## GitHub Pagesで公開する方法

1. このリポジトリをGitHubにプッシュ
2. リポジトリの「Settings」→「Pages」に移動
3. 「Source」で「Deploy from a branch」を選択
4. 「Branch」で「main」（または「master」）を選択し、「/ (root)」を選択
5. 「Save」をクリック

数分後、`https://[ユーザー名].github.io/[リポジトリ名]/` でサイトにアクセスできます。

### 注意事項

- リポジトリ名が `[ユーザー名].github.io` の場合、ルートパス（`/css/style.css`など）がそのまま機能します
- それ以外のリポジトリ名の場合、URLにリポジトリ名が含まれるため、パスの調整が必要な場合があります
